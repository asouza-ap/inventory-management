Key Architectural Patterns

Singleton Filter Composable

useFilters.js exports refs declared at module scope — shared across all views without prop drilling or Vuex. Every view calls getCurrentFilters() and watches the refs to re-fetch on change.

Reactive Data Pattern

Raw API results stored in ref([]). Derived values (filtered lists, totals, chart data) live in computed() — cached until dependencies change. No direct mutation of computed properties.

In-Memory Filtering

All JSON loaded at startup into Python dicts. apply_filters() iterates in-memory lists on each request. No query planner — works fine at demo scale. Quarter filter maps Q1-4 2025 to month arrays at runtime.
